# Plate 单元计算结果

## 1. 测试算例概述

使用 STAP++ 程序对 Plate 4 节点 Mindlin-Reissner 板弯曲单元（双线性插值）进行了数值测试。该单元采用选择性缩减积分策略：弯曲部分使用 2×2 Gauss 积分，剪切部分使用 1 点缩减积分（避免剪切闭锁）。

| 测试 | 目的 | 问题类型 |
|------|------|----------|
| 悬臂板验证 (Cantilever) | 验证基本弯曲刚度和应力 | 悬臂板弯曲 |
| 收敛性分析 (Convergence) | 确定网格加密时的收敛率 | 悬臂板弯曲 |

公共参数：E = 2.0×10¹¹ Pa，ν = 0.3，t = 0.1 m，板宽 W = 1.0 m，板长 L = 10.0 m。

**解析解（Euler-Bernoulli 梁理论参考）：**

对于板宽 W = 1.0 m，截面惯性矩 I = W·t³/12 = 8.3333×10⁻⁵ m⁴：
- δ_tip = PL³/(3EI) = 1000×1000/(3×2×10¹¹×8.3333×10⁻⁵) = 20.0 mm
- M_fixed = PL/W = 10000 N·m/m（根部 x=0 处弯矩）
- Q = P/W = 1000 N/m（沿宽度均布剪力）

> **注意：** 板弯曲的精确解析解与宽长比有关。对于 W/L = 0.1 的窄板（自由边界），其行为接近 Euler-Bernoulli 梁。本文以梁理论解 20.0 mm 为参考值。

## 2. 悬臂板单元素验证

输入文件：[data/plate_cantilever.dat](data/plate_cantilever.dat)

**工况：** 单 Plate 单元（4 节点），L = 10.0 m × W = 1.0 m。左端（x=0）两节点完全固支（bcode: 1,1,1），右端（x=10）两节点各施加 Pz = −500 N（合计 −1000 N，沿自由端均匀分布）。

### 2.2 单元应力（单元中心 x=5.0 m 处）

| Mx (N·m/m) | My (N·m/m) | Mxy (N·m/m) | Qx (N/m) | Qy (N/m) |
|------------|------------|-------------|----------|----------|
| 5.000e+03 | 4.032e+02 | ~0 | −1.000e+03 | ~0 |

**验证：**
- Mx = P·(L/2)/W = 1000×5/1 = 5000 N·m/m ✓（单元中心弯矩精确）

- My ≈ 403 N·m/m = Poisson 耦合效应产生的横向弯矩（窄板平面应力，My 应较小）
- Mxy ≈ 0，Qy ≈ 0 ✓（纯弯曲无扭转）

## 3. 收敛性分析

对悬臂板条使用不同密度的均匀网格（每行元素等长），网格从 1 个元素逐渐加密到 64 个元素。每级网格记录自由端中点（x=10, y=0.5）的竖向位移 w。

> **结论：** 弯矩分布与解析解完全一致。弯曲部分使用 2×2 完全积分，刚度矩阵精度良好。

### 3.4 剪力预测

8×2 网格中所有单元的 Qx 均为 −1000 N/m，与理论值一致。然而在更高密度网格（16×4）中，Qx 出现局部振荡（元素间波动可达 ±30%）。这是因为：

- 剪切项采用了 **单点缩减积分**（中心点），虽然有效避免了剪切闭锁，但牺牲了剪力的逐元素精度
- 剪力振荡在位移层面不产生显著影响（挠度仍收敛至正确值）
- 这是 Mindlin-Reissner 板单元缩减积分的已知行为

## 4. 讨论

### 4.1 剪切闭锁

若不采用缩减积分（剪切项也用 2×2 Gauss），薄板（t/L = 0.01）将发生严重剪切闭锁，刚度被高估数倍。选择性缩减积分策略（K = Kb_2×2 + Ks_1pt）成功避免了这一问题。

### 4.2 收敛率

位移的收敛速率约为 O(h²)，与双线性单元的预期收敛率一致：
- 2×1 → 4×1： 误差从 9.8% 降至 3.5%（约 2.8× 改善）
- 4×1 → 8×2： 误差从 3.5% 降至 1.5%（约 2.3× 改善）
- 8×2 → 16×4：误差从 1.5% 降至 1.2%（约 1.3× 改善，接近渐近收敛区）

### 4.3 局限性

1. **剪力精度：** 缩减积分产生的剪力在较密网格中可能出现局部振荡
2. **窄板行为：** W/L = 0.1 的窄板需要使用较密网格才能精确捕捉挠度
3. **边界条件：** 目前仅支持固定端（θx,θy,w 全约束）和自由端，简支边界条件需要额外处理
4. **四边形网格：** 仅支持矩形单元的正交网格，未实现歪斜四边形

### 4.4 与 Q4 平面应力单元比较

| 特性 | Q4 单元 | Plate 单元 |
|------|---------|------------|
| 物理维度 | 2D 平面应力 | 薄/中厚板弯曲 |
| 每节点 DOF | 2 (u, v) | 3 (θx, θy, w) |
| 刚度矩阵尺寸 | 8×8 | 12×12 |
| 积分策略 | 2×2 Gauss | 弯曲 2×2 + 剪切 1pt |
| 剪切闭锁 | 无（无剪切变形） | 需缩减积分避免 |
| 主要应用 | 平面受力结构 | 横向受载薄板 |
